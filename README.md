Capstone Week 3 - Contact Form Project
Project Overview

This project is part of the Capstone Week 3 assignment. It demonstrates a basic Git workflow including branching, pull requests, code review, and version tagging.
Features

    Contact form page with name, email, message fields and submit button

Project Structure

capstone_week3/ ├── contact.html # Contact form page ├── intro_ranjan.txt # Introduction file └── README.md # Project documentation
Git Workflow Used

    Forked the repository
    Created branch: feature-contact-form
    Added contact.html
    Committed and pushed changes
    Created Pull Request
    Code reviewed and merged into main
    Tagged release: v1.0-contact-form

How to Run

    Clone the repo
    Open contact.html in your browser

Version

    v1.0-contact-form - Initial contact form release

Technologies Used

    HTML
